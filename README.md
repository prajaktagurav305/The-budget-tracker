# Vegetable Market Inventory Management

## About the Project
A beginner-level Python project that simulates a simple vegetable market inventory system using Object-Oriented Programming (OOP).

## Features
- Initialize products with price and quantity.
- Track available stock.
- Process product sales.
- Prevent sales when requested quantity exceeds available stock.
- Automatically update remaining inventory.

## Technologies Used
- Python 3

## Concepts Practiced
- Classes and Objects
- Constructors (`__init__`)
- Instance Variables
- Methods
- Conditional Statements
- Object State Management

## Sample Output
```text
Remaining stock: 7
Insufficient stock
```

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the Python program.

```bash
python market.py
```
